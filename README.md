🍔 Foodie – Food Ordering Website

A modern and responsive Food Ordering Website developed using HTML5 and CSS3.
This project provides a clean and user-friendly interface for browsing food items, viewing the cart, and completing the checkout process.

✨ Features

- 🏠 Attractive Home Page
- 🍕 Food Categories
- ⭐ Featured Food Items
- 📋 Detailed Menu Page
- 🛒 Shopping Cart Page
- 💳 Checkout Page
- 📍 Contact Us Section
- ❤️ Customer Reviews
- 🚚 Fast Delivery Information
- 📱 Responsive Design
- 🎨 Modern UI with Hover Effects
- 🖼️ Food Images and Professional Cards

🛠️ Technologies Used

- HTML5
- CSS3

📄 Pages

🏠 Home

Introduction to Foodie with featured foods, categories, about section, reviews and contact information.

🍕 Menu

Displays different food items with images, descriptions and prices.

🛒 Cart

Shows selected food items, quantities and order summary.

💳 Checkout

Contains customer delivery details, payment options and order summary.

🎯 Project Objective

The main objective of this project is to create a simple, attractive and responsive food ordering website using front-end web development technologies.
